# DentiCash v3
نسخه سوم DentiCash با ذخیره‌سازی محلی، تقویم شمسی، ثبت درمان و درآمد ساعتی همراه با مدت کار، اهداف ماهانه، کارت «باقی‌مانده تا هدف»، پیشنهاد افزایش هدف بر اساس میانگین دریافتی، گزارش‌ها، حالت تاریک و Backup/Restore.

برای ثبت درآمد ساعتی، در فرم «ثبت درآمد» نوع «درآمد ساعتی» را انتخاب و مدت کار و مبلغ دریافتی را وارد کنید. شاخص قدیمی «درآمد ساعتی» از داشبورد و گزارش خلاصه حذف شده است.
تعطیلات رسمی به‌صورت آنلاین وابسته نشده‌اند؛ جمعه پیش‌فرض غیرکاری است و تعطیلی‌های دیگر از تقویم قابل تغییرند.

برای انتشار در GitHub Pages، محتویات ZIP را مستقیماً در ریشه مخزن قرار دهید؛ فایل index.html باید در ریشه باشد.


## آپدیت ثبت درآمد
- در هر ثبت درآمد، تاریخ و ساعت ثبت ذخیره می‌شود و در لیست و گزارش جزئیات درآمدها نمایش داده می‌شود.
- فیلد نام بیمار به فرم ثبت درآمد اضافه شده است.
- انتخاب نوع «درآمد ساعتی» و فیلد مدت کار حذف شده؛ ساعت، زمان ثبت درآمد است نه نوع درآمد.
- داده‌های قدیمی بدون ساعت یا نام بیمار همچنان قابل مشاهده‌اند و با ویرایش می‌توان اطلاعاتشان را تکمیل کرد.
