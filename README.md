# DentiCash v4 — نسخه توسعه اولیه مدیریت مطب

## ویژگی‌های نسخه
- حفظ هسته نسخه قبلی: داشبورد، درآمد واقعی، تعرفه درمان، اهداف، تقویم کاری، گزارش‌ها، حالت تاریک و Backup/Restore.
- تب جدید «پرونده‌ها» با کد دستی یکتا، نام، شماره تماس، تاریخ تولد و یادداشت.
- چارت دندانی تعاملی با انتخاب شماره دندان و نمایش دندان‌هایی که سابقه درمان دارند.
- ثبت تاریخچه درمان، چند دندان برای هر اقدام و وضعیت انجام‌شده/برنامه‌ریزی‌شده/پیگیری.
- افزودن عکس از دوربین یا گالری و اتصال تصاویر به پرونده؛ تصاویر به JPEG فشرده می‌شوند.
- اتصال ثبت دریافتی به پرونده بیمار و مشاهده دریافتی‌های متصل در حساب بیمار.
- ذخیره محلی در مرورگر؛ داده‌ها همراه Backup JSON ذخیره می‌شوند.
- قابلیت Devil Trigger در این نسخه وجود ندارد.

## نصب / انتشار
محتویات این پوشه را در ریشه مخزن GitHub Pages قرار دهید و Commit کنید. فایل `index.html` باید در ریشه باشد.

## نکات مهم
- این نسخه توسعه اولیه است؛ پیش از استفاده بالینی واقعی، روی کپی آزمایشی تست شود.
- اطلاعات ذخیره محلی فقط در همان مرورگر/دستگاه در دسترس است. برای جلوگیری از دست‌رفتن داده‌ها، Backup منظم بگیرید.
- عکس‌ها در داده‌های محلی مرورگر ذخیره می‌شوند و ممکن است حجم ذخیره را سریع پر کنند؛ قبل از بارگذاری تعداد زیادی عکس، تست و پشتیبان‌گیری کنید.
- نمودار فعلی از شماره‌گذاری FDI برای ۳۲ دندان دائمی استفاده می‌کند؛ وضعیت‌های بالینی پیشرفته و دندان‌های شیری هنوز مدل نشده‌اند.
- این نسخه هنوز سرور، ورود کاربری، همگام‌سازی چنددستگاهی یا صورتحساب رسمی مستقل ندارد. معماری اتصال بعدی باید با سرویس امن و کنترل دسترسی پیاده شود.
- قبل از جایگزینی نسخه آنلاین، از اطلاعات قبلی از داخل تنظیمات Backup بگیرید. داده‌های localStorage به آدرس/مبدأ و مرورگر وابسته‌اند و انتقال فایل‌های GitHub به تنهایی داده‌ها را منتقل نمی‌کند.
